# 🌐 AI Translator Chatbot

## 📌 Project Overview
The **AI Translator Chatbot** is a Python-based application developed using Streamlit. It allows users to translate text from one language into another through a simple and interactive chat interface.

The application supports multiple languages and also provides audio output using Text-to-Speech technology. It includes a synonym feature that helps users explore alternative English words.

## ✨ Features

- 🌍 **Multiple Language Translation:** Translate text into different languages, including English, Urdu, French, German, Spanish, Arabic, Hindi, and more.
- 💬 **Interactive Chat Interface:** Simple and user-friendly interface built with Streamlit.
- 🔊 **Text-to-Speech:** Listen to translated text using Google Text-to-Speech (gTTS).
- ⚡ **Error Handling:** Handles translation errors and connection issues.

## 🛠️ Technologies Used

- Python
- Streamlit
- Translate Library
- Google Text-to-Speech (gTTS)
- NLTK (WordNet)
- Pandas (if applicable)
